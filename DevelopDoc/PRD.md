## 1. 한 줄 요약

사용자가 **종목과 질문**을 입력하면, 금융감독원 전자공시(**OpenDART**)의 재무·공시 데이터를 **필요한 최소 기간만** 불러와 계산하고, 화면 **왼쪽에는 근거 차트**, **오른쪽에는 분석 글**을 보여주는 질문형 기업 분석 웹 서비스. 분석 글은 숫자를 되풀이하지 않고, 계산 결과가 사업에 무엇을 뜻하는지 **투자 판단에 참고할 해석(투자 포인트)**을 **스마트폰 한 화면 분량**으로 제시하며, **Google 뉴스 RSS 기사 링크를 맥락 단서**로 함께 보여준다.

> 본 프로젝트는 **바이브코딩 수업용 비상업 프로젝트**이다. 수익을 내지 않으며, 가급적 무료 API·서비스만으로 만든다 (§2.3).

## 2. 배경 및 문제 정의

### 2.1 배경
- 기업의 실적과 경영사항은 DART(전자공시시스템)에 모두 공개되어 있지만, 원문은 **보고서 단위의 긴 문서**로 흩어져 있다.
- 투자자가 실제로 궁금한 것은 "이 회사 요즘 어때?", "왜 이익이 줄었어?", "경쟁사보다 나아?" 같은 **질문**이다. 정해진 대시보드는 그 질문에 딱 맞는 답을 주지 못한다.

### 2.2 문제
| # | 사용자가 겪는 문제 | 결과 |
|---|---|---|
| P1 | 궁금한 질문 하나에 답하려고 여러 보고서를 열어 숫자를 찾아야 한다 | 시간이 많이 든다 |
| P2 | 3분기 보고서는 누적 실적이라 분기별 실적(특히 4분기)을 직접 계산해야 한다 | 계산 실수 |
| P3 | 숫자가 변한 "이유"는 공시가 아니라 뉴스에 흩어져 있다 | 맥락 파악이 어렵다 |
| P4 | 경쟁사 비교를 하려면 여러 회사 데이터를 따로 모아야 한다 | 비교를 포기한다 |
| P5 | 일반 AI 챗봇은 숫자를 지어내기도 하고 근거를 보여주지 않는다 | 믿을 수 없다 |
| P6 | 사이트마다 PER·PBR 계산 기준이 다르다 | 어떤 숫자를 믿어야 할지 모른다 |

### 2.3 프로젝트 성격과 원칙
| 원칙 | 내용 |
|---|---|
| **비상업** | 바이브코딩 수업용 프로젝트. 광고·유료 기능·결제 없음. 화면에 비상업 서비스임을 안내 (F-Z6) |
| **무료 우선** | 데이터·호스팅·DB·로그인은 모두 무료 API·무료 플랜으로 구성 |
| **유료는 하나만** | 유료는 **OpenAI GPT API** 하나. 질문당 필요한 데이터만 AI에 넘겨 **토큰(AI 사용량 단위)을 아낀다** |
| **숫자는 서버가 계산** | AI는 계산하지 않는다. AI는 ① 질문을 정해진 분석 요청 형식으로 바꾸고 ② 서버가 계산한 결과를 글로 설명하는 역할만 한다 |
| **서비스 범위 한정** | **국내 상장 주식회사의 실적·재무·공시(경영사항)·주가 지표·관련 뉴스**에 관한 질문에만 답한다. 그 밖의 질문은 정해진 문구로 **공손하게 거절**한다. 범용 AI 챗봇처럼 쓰이는 오남용을 막기 위함이다 (§6.3.1) |

### 2.4 수업 워크플로우와의 관계
본 프로젝트는 수업에서 제공된 5단계 워크플로우(Step 1~5)를 따르되, 다음과 같이 바꿔 적용한다.

| 수업 워크플로우 | 본 프로젝트 |
|---|---|
| CSV 파일 업로드 | **OpenDART API 조회로 전적으로 대체** (CSV 업로드 기능 없음) |
| 업로드 데이터 미리보기 | 분석에 **사용된 데이터 표**(행·열 수, 자료형, 기간)를 결과 화면에서 보여줌 |
| 결과 내보내기(다운로드) | **구현 제외** |
| 프로젝트 공유·열람/편집 권한 | **구현 제외** (프로젝트는 소유자 본인만 접근) |
| 확장 기능 택 1 | **② 두 데이터셋 결합**: 재무 데이터(OpenDART) + 주가 데이터(금융위원회) |
| (추가) | **뉴스 단서**(Google 뉴스 RSS) — 수업 워크플로우에 없는 본 프로젝트 고유 기능 |

## 3. 목표 / 비목표

### 3.1 핵심 목표 (Goals)
| ID | 목표 | 설명 |
|---|---|---|
| G1 | **질문하면 바로 답** | 종목+질문 한 번 입력으로 차트와 분석 글을 받는다 (별도 데이터 준비 단계 없음) |
| G2 | **근거가 보이는 답** | 모든 숫자는 차트·표로, 맥락은 뉴스 링크로 근거를 함께 보여준다 |
| G3 | **정확한 숫자** | 계산은 서버가 버전이 붙은 하나의 계산식으로 수행한다. AI가 만든 숫자는 쓰지 않는다 |
| G4 | **최소 비용** | 질문에 필요한 최소 기간·최소 데이터만 조회하고 AI에 넘긴다 |
| G5 | **다시 볼 수 있는 분석** | 질문·데이터 버전·분석 설정·결과를 저장해, 나중에 같은 조건으로 재실행하면 같은 숫자가 나온다 |
| G6 | **공정하고 안전한 사용** | 회원별 사용 한도, 단계·시간·비용 상한으로 과다 사용과 무한 실행을 막는다 |

### 3.2 비목표 (Non-Goals)
- 매수·매도 추천, 목표주가 제시 등 **투자 자문 행위**
- **CSV 등 파일 업로드** (데이터는 OpenDART에서만 가져옴)
- **결과 다운로드·내보내기**
- **외부 공유·다른 회원과의 공동 편집**
- **뉴스 기사 본문의 저장·화면 표시** (링크와 우리가 만든 짧은 요지만 표시)
- AI가 작성한 Python·SQL 코드의 생성·실행
- **주식·상장 기업 분석과 무관한 일반 질의응답** (잡담, 숙제·코딩 도움, 번역, 비주식 자산 전망 등 — 범용 AI 챗봇 역할을 하지 않음)
- 실시간 주가 시세, 트레이딩 기능 (주가는 **전 거래일 종가** 기준만)
- 아이디·비밀번호 가입, 구글 외 로그인
- 광고·유료 기능·결제 등 **상업적 운영**
- 모바일 전용 앱 (반응형 웹으로만 대응), 해외 기업

## 5. 핵심 사용자 시나리오

0. **첫 방문 (비로그인)**
   화면 가운데에 **질문 입력창만 있는 대기화면**이 보이고, 그 아래에 **SK하이닉스 예시 분석**(미리 만들어 둔 답변, 좌 차트·우 분석 글)이 보인다. 입력창에 질문을 입력하려 하거나 예시의 버튼을 누르면 "로그인 후 이용할 수 있습니다" 안내와 함께 로그인 페이지로 이동한다.
1. **로그인**
   **구글 계정**으로 버튼 한 번에 로그인. 처음이면 약관·개인정보 처리방침 동의.
2. **질문**
   빈 대기화면의 입력창에 "SK하이닉스 최근 실적 어때?"를 입력한다. 기간을 말하지 않았으므로 서비스가 **필요한 최소 기간**(최근 4개 분기)을 스스로 정해 분석한다. 화면 위쪽에 "오늘 남은 질문 19/20"이 보인다.
3. **결과 확인 (좌우 화면)**
   - **왼쪽**: 분기별 매출·영업이익 차트, 지표 카드, (필요하면) 경쟁사 비교 차트. 각 차트는 "표로 보기"로 바꿀 수 있다.
   - **오른쪽**: 결론 → 근거 숫자 → 뉴스 단서(기사 제목·언론사·날짜·링크) → 주의사항 순서의 분석 글.
   - 화면 위쪽에 분석 기준(기업, 기간, 기준 보고서, 계산식 버전)이 표시된다.
4. **기간 지정 질문**
   "2023년부터 2024년까지 분기별 영업이익률 추이 보여줘"처럼 **기간을 말하면 그 기간 그대로** 조회한다.
5. **복합 질문**
   "직전 분기 대비 영업이익 변화와, 감소한 경쟁사를 비교해줘"처럼 여러 계산이 필요한 질문은 **분석 계획 카드**가 먼저 뜬다 ("① 기간 필터 ② 분기 집계 ③ 경쟁사 비교"). [분석 시작]을 누르면 진행 상태가 표시되고, 도중에 [취소]할 수 있다.
6. **필터 바꿔 보기**
   결과 화면의 기간·비교 기업 필터를 바꾸면 왼쪽 차트와 표가 **같은 조건으로 함께** 다시 계산된다 (AI를 다시 부르지 않음). 오른쪽 글에는 "원래 조건 기준 설명입니다 · [설명 다시 쓰기]"가 표시된다.
7. **다시 보기**
   "내 분석" 목록에서 지난 분석을 열고 [같은 조건으로 재실행]을 누르면, 같은 데이터 버전 기준으로 같은 숫자가 나온다. 새 공시가 나와 데이터가 바뀌었으면 "새 데이터 버전 있음" 표시가 뜬다.

## 6. 기능 요구사항

> 우선순위와 도입 단계는 수업 워크플로우의 **Step 1~5**로 표시한다 (§12).

### 6.1 질문 입력·대기화면 (F-Q)
| ID | 요구사항 | Step |
|---|---|---|
| F-Q1 | 첫 화면은 **질문 입력창만 있는 빈 대기화면**이다 (입력창 아래 예시 질문 3~4개) | 1 |
| F-Q2 | 사용자는 **종목(회사명 또는 종목코드) + 질문**을 한 문장으로 입력한다. 별도의 데이터 불러오기 단계는 없다 | 1 |
| F-Q3 | 종목을 알아볼 수 없거나 여러 후보가 있으면 되묻는다 (예: "현대차를 말씀하신 건가요, 현대모비스인가요?") | 1 |
| F-Q4 | 결과 화면 아래에 이어서 질문할 수 있는 입력창을 둔다 (같은 프로젝트 안의 후속 질문) | 2 |
| F-Q5 | 검색·질문은 **로그인한 회원만** 가능하다 | 1 |

### 6.2 조회 기간 결정 (F-R) — 토큰 절약
| ID | 요구사항 | Step |
|---|---|---|
| F-R1 | 질문에 기간이 **없으면**, 질문 유형에 맞는 **최소 필요 기간**만 조회한다 (기본표 아래) | 1 |
| F-R2 | 질문에 기간이 **있으면** 그 기간으로 조회한다 (예: "2023년", "최근 3년", "2024년 2분기") | 1 |
| F-R3 | 조회 가능한 범위는 **2015년 1분기 ~ 최신 보고서**다. 범위를 벗어나면 가능한 범위를 안내한다 | 1 |
| F-R4 | 결과 화면에 **실제 사용한 기간과 그 기간을 고른 이유**를 표시한다 (예: "기간 미지정 → 최근 4개 분기") | 1 |

**질문 유형별 최소 조회 기간 (기간 미지정 시)**
| 질문 유형 | 예 | 조회 기간 |
|---|---|---|
| 최근 실적·현황 | "요즘 실적 어때?" | 최근 4개 분기 |
| 추이·흐름 | "영업이익 추세 보여줘" | 최근 8개 분기 |
| 연간 비교 | "연도별 매출 비교" | 최근 3개 연도 |
| 변화 원인 | "왜 이익이 줄었어?" | 최근 2개 분기 + 해당 기간 뉴스 |
| 경쟁사 비교 | "경쟁사보다 나아?" | 최근 1개 분기 (TTM 지표는 최근 4개 분기) |
| 공시·이벤트 | "최근 유상증자 있었어?" | 최근 12개월 공시 |

### 6.3 분석 처리 (F-N)
| ID | 요구사항 | Step |
|---|---|---|
| F-N1 | AI는 질문을 **정해진 분석 요청 형식**(기업, 지표, 기간, 묶음 단위, 연산, 차트 종류)으로만 바꾼다 | 1 |
| F-N2 | 서버는 분석 요청의 기업·지표·기간·연산이 **허용 목록에 있는지 검사**한 뒤 계산한다 | 1 |
| F-N3 | 허용 연산: **합계, 평균, 개수, 그룹별 집계**(분기·연도·기업·섹터별) + 지표 계산(증감률, 이익률, ROE, PER·PBR 등 §6.9) | 1 |
| F-N4 | AI가 만든 코드(Python·SQL)는 생성하지도 실행하지도 않는다 | 1 |
| F-N5 | 존재하지 않는 지표·기업·기간을 물으면 **되묻거나 "지원하지 않는 질문"으로 안내**한다 | 1 |
| F-N6 | 데이터 없음, 계정 값 없음, 허용 범위 초과(기간·기업 수)는 이유와 함께 오류로 안내한다 | 1 |
| F-N7 | **AI 장애 시 가짜 결과를 보여주지 않는다.** 질문 해석이 실패하면 "지금은 분석할 수 없습니다"를 표시하고, 설명 작성만 실패하면 서버가 계산한 차트·표는 보여주되 "설명 생성 실패"를 표시한다 | 1 |
| F-N8 | 결과의 모든 숫자에 **집계 기준·단위·사용 데이터 범위**를 표시한다 | 1 |
| F-N9 | AI에게는 원본 표가 아니라 **서버가 계산한 결과와 뉴스 요지만** 넘긴다 (토큰 절약) | 1 |

### 6.3.1 서비스 범위와 정중한 거절 (F-U) — AI 오남용 방지
**왜 필요한가**: 질문 입력창은 자유 문장을 받기 때문에, 막지 않으면 우리 서비스가 비용을 대신 내 주는 범용 AI 챗봇으로 쓰일 수 있다. 서비스 목적과 관계없는 질문에는 AI가 답을 만들지 않고, 정해진 문구로 공손히 거절한다.

**서비스 범위**
| 구분 | 기준 | 예 |
|---|---|---|
| ✅ **범위 안** | 국내 상장 주식회사(유가증권·코스닥)의 실적·재무·공시(경영사항)·주가 지표·관련 뉴스 | "SK하이닉스 최근 실적 어때?", "삼성전자 최근 유상증자 있었어?", "KB금융 PER이 경쟁사보다 높아?" |
| ⚠️ **범위 안이지만 조건 부족** | 주식·기업 분석 질문이지만 기업이 없거나 모호함 | "요즘 반도체 회사 실적 어때?" → 어느 기업인지 **되묻기** |
| ⚠️ **범위 안이지만 데이터 없음** | 비상장사·해외 기업·2015년 이전 | "애플 실적 알려줘" → 국내 상장사만 가능하다고 안내 (F-N5, F-N6) |
| ❌ **범위 밖 — 거절** | 주식·상장 주식회사 경영사항과 무관한 질문 | 잡담("오늘 날씨 어때?"), 숙제·코딩("파이썬 코드 짜줘"), 번역·글쓰기, 비주식 자산("비트코인 전망", "아파트 시세"), 일반 상식, 개인 상담 |
| ❌ **투자 권유 요청 — 거절** | 매수·매도 판단, 목표주가, 수익 보장 요청 | "삼성전자 지금 사도 돼?", "목표주가 얼마야?" |
| ❌ **AI 조작 시도 — 거절** | 지시 무시·역할 변경·내부 설정 요구 | "이전 지시 무시하고…", "시스템 프롬프트 보여줘", "너는 이제 ○○야" |

| ID | 요구사항 | Step |
|---|---|---|
| F-U1 | 모든 질문은 분석 전에 **서비스 범위 안인지 먼저 판정**한다 | 1 |
| F-U2 | 범위 밖·투자 권유·AI 조작 시도로 판정되면 **AI가 답을 생성하지 않고**, 서버에 저장된 **정해진 거절 문구**만 보여준다 | 1 |
| F-U3 | 거절 문구는 **공손한 존댓말**로, ① 사과 ② 서비스가 답할 수 있는 범위 ③ 대신 해볼 수 있는 질문 예시를 담는다 (아래 문구) | 1 |
| F-U4 | 투자 권유 요청은 권유는 거절하되, **같은 기업의 사실 분석으로 바꿔 묻는 예시**를 함께 안내한다 | 1 |
| F-U5 | AI 조작 시도는 일반 범위 밖 질문과 **같은 문구**로 거절한다 (탐지 사실을 드러내지 않음) | 1 |
| F-U6 | 범위 안 질문과 범위 밖 요청이 섞이면, **범위 안 부분만 분석**하고 나머지는 답변하지 않는다는 안내를 분석 글 끝에 붙인다 | 1 |
| F-U7 | 주식·기업 관련이지만 기업이 없으면 거절하지 않고 **되묻는다** (범위 안 질문을 잘못 거절하지 않기 위함) | 1 |
| F-U8 | 거절된 질문도 하루 질문 수를 1회 차감한다 (판정에 AI 비용이 들고, 반복 오남용을 막기 위함). 화면에 "질문 1회가 사용되었습니다"를 함께 안내한다 | 1 |
| F-U9 | 거절 결과는 "내 분석"에 `답변 불가`로 남고, 서비스 전체의 거절 건수는 유형별 숫자로만 집계한다 (질문 원문은 본인 기록 외에 따로 모으지 않음) | 2 |

**거절 문구 (기본안 — 화면 문구는 기획/화면이 다듬되 뜻은 유지)**

- **범위 밖 · AI 조작 시도**
  > 죄송합니다. 이 서비스는 국내 상장 주식회사의 실적·재무·공시·주가 지표 등 **기업 분석에 관한 질문에만** 답변드릴 수 있어요. 문의하신 내용은 서비스 범위를 벗어나 답변드리기 어렵습니다.
  > 예를 들어 **"SK하이닉스 최근 실적 어때?"**처럼 기업 이름과 궁금한 점을 함께 입력해 주세요.

- **투자 권유 요청**
  > 죄송합니다. 이 서비스는 **매수·매도 판단이나 목표주가 같은 투자 권유는 드릴 수 없어요.** 대신 공시 자료를 바탕으로 한 사실 분석은 도와드릴 수 있습니다.
  > 예: **"○○ 최근 4개 분기 실적과 주요 공시 알려줘"**

- **섞인 질문 (분석 글 끝에 덧붙임)**
  > 질문 중 기업 분석과 관련 없는 부분은 이 서비스의 범위를 벗어나 답변드리지 않았습니다. 양해 부탁드립니다.

### 6.4 결과 화면 — 좌 차트 / 우 분석 글 (F-V)
| ID | 요구사항 | Step |
|---|---|---|
| F-V1 | 결과 화면은 **왼쪽 = 차트 모음, 오른쪽 = 분석 글**로 나눈다 | 1 |
| F-V2 | 위쪽에 분석 기준 바: 기업, 기간(선정 이유), 기준 보고서, 주가 기준일, 계산식 버전 | 1 |
| F-V3 | 왼쪽: 질문에 필요한 차트만 보여준다 (지표 카드, 막대·선 차트, 비교 차트). 개수는 질문에 따라 1~4개 | 1 |
| F-V4 | 모든 차트는 **제목·축·단위·범례**를 갖고, **"표로 보기"**로 바꿀 수 있다 | 1 (범례·표 대체는 4에서 완성) |
| F-V5 | **차트의 값은 같은 화면의 표 값과 반드시 같다** | 1 |
| F-V6 | 오른쪽 분석 글 순서: ① 결론(2문장) ② **투자 포인트**(긍정 요인·위험 요인·다음에 확인할 점, 2~4개) ③ 근거 숫자(차트 연결, 접어서 표시) ④ 뉴스 단서 ⑤ 주의사항·한계(작은 글씨, 항상 보임) | 1 (뉴스 단서는 3) |
| F-V7 | 분석 글의 숫자는 왼쪽 차트·표의 숫자와 일치해야 하며, 일치하지 않는 문장은 내보내지 않는다 | 1 |
| F-V8 | "사용된 데이터" 영역: 분석에 쓴 데이터 표 미리보기 (행·열 수, 항목별 자료형, 기간) | 1 |
| F-V9 | 모바일(좁은 화면)에서는 **차트 → 분석 글** 순서로 위아래로 쌓는다 | 1 |
| F-V10 | 분석 글에 `AI 작성` 표시를 붙인다 | 1 |
| F-V11 | **분량 (v0.7.1 개정): 결론 앞부분은 첫 화면, 나머지와 투자 포인트는 이어서.** 결론은 필요한 만큼 2~15문장, 너비 375px 화면에서 결론 앞 3문장(질문의 답과 핵심)이 첫 화면(약 650px) 안에 들어온다. 투자 포인트는 관점별 최대 8개·한 개 160자 이내, 결론 포함 합계 공백 포함 3,500자 이내 (이전: 한 화면 320자 → v0.7 결론 5문장·1,300자 — 인사이트 분석을 담으려고 늘림). 근거 숫자는 차트와 겹치므로 접어서 보여주고, 주의사항은 숨기지 않고 투자 포인트 아래에 작은 글씨로 둔다 (한 화면 분량 계산에서 제외) | 1 |
| F-V12 | **투자 포인트는 해석이다.** 숫자를 되풀이하지 않고 숫자가 사업에 무엇을 뜻하는지 적당한 수준으로 추론한다 (예: "매출은 늘었지만 영업이익률이 낮아져 비용 부담이 커지는 흐름"). 추론 문장은 근거가 된 **숫자 ID 또는 뉴스를 하나 이상 반드시 연결**하고, 추정이면 "~로 보입니다"처럼 추정임을 드러낸다. **원인·지속성·다음 분기 흐름의 추론은 주어진 자료(공시·주가 API 숫자, 뉴스 RSS) 안에서 할 수 있다** — 추론 문장은 "~로 예상됩니다·보입니다·추정됩니다·가능성이 있습니다"로 추론임을 밝히고 화면에 (추정)으로 표시한다. 단정한 원인 문장("~때문입니다")은 내보내지 않는다 (v0.7.1 개정, 이전: 원인 추정은 뉴스가 있을 때만). 근거가 연결되지 않은 추론 문장은 내보내지 않는다 | 1 (뉴스 근거는 3) |
| F-V13 | 투자 포인트는 **판단을 돕는 정보**이며, 매수·매도·보유 의견, 목표주가, 주가·수익률 예상은 쓰지 않는다 (§9, §6.3.1) | 1 |

|---|---|---|---|

| F-E2 | 실적 추이 차트 | 분기·연간 매출·영업이익·순이익 (막대/선) | 1 |
| F-E3 | 증감 차트 | YoY, QoQ(직전 분기 대비) | 1 |

| F-E6 | 주요 공시 목록 | 중요 공시만 태그·날짜·DART 원문 링크와 함께 | 1 |

### 6.6 뉴스 단서 (F-W)
| ID | 요구사항 | Step |
|---|---|---|
| F-W1 | 질문과 관련된 뉴스를 **Google 뉴스 RSS**(키 없이 쓰는 공개 검색 피드)로 찾는다 (질문의 기업명·핵심어·분석 기간) | 3 |
| F-W2 | 관련도 상위 **최대 5건**의 기사 제목(본문을 확인할 수 있으면 본문까지)을 바탕으로, 질문과 관련된 핵심 내용을 AI가 1~2문장 **요지**로 정리한다 | 3 |
| F-W3 | 분석 글의 "뉴스 단서"에 **기사 제목·언론사·발행일·원문 링크·요지**를 표시한다 | 3 |
| F-W4 | 뉴스는 **단서**로만 쓴다. 숫자 근거는 공시 데이터만 쓰며, 화면에 "뉴스는 참고용 단서입니다"를 표시한다 | 3 |

### 7.1 확인된 데이터 제약
- OpenDART 재무정보는 **2015년 이후**만 제공 → 조회 가능 기간의 근거.
- 보고서 구분: `11013`(1분기), `11012`(반기), `11014`(3분기), `11011`(사업보고서). **4분기 단독 보고서 없음.**
- OpenDART 인증키당 **일일 요청 한도**(약 2만 건, 초과 시 오류 `020`).
- 주가 API: **다음 영업일 오후 1시 이후** 갱신, 개발 계정 **하루 10,000건**, 이용 조건 **"출처표시, 상업적 이용금지, 변경금지"** → 비상업 수업용으로 조건에 맞음.
- Google 뉴스 RSS: 공식 API가 아닌 **공개 피드**. 키·가입 불필요, 공개된 호출 한도 없음(과도한 호출은 차단될 수 있음), 한 번에 약 100건. 응답은 **제목·언론사·발행일·링크**만 있고 요약문·본문은 없다. 이용 조건은 **비상업 용도**로 알려져 있어 본 프로젝트와 맞는다. 결과를 AI 입력에 써도 되는지는 약관에 명시가 없어 **구현 전 확인** (TECH T7). *(2026-09-29 시험 호출: "SK하이닉스" 한국어 기사 105건)*
- 기사 본문은 **언론사 저작물**이다 → 본문 저장·표시 금지, 언론사 사이트의 크롤링 허용 규칙(robots.txt)을 구현 전 확인 (TECH_SPEC).
- 사용하지 않는 뉴스 출처 (2026-09-29 조사): **네이버 검색 API**는 개발자센터 신규 신청이 중단되고(7/30) 유료 API HUB로 이관되며, 검색 결과의 AI 활용이 금지됨 / **다음(카카오) 검색 API**는 뉴스 검색이 없음 / **빅카인즈** Open API는 유료 / **GDELT**는 한국어 기사가 거의 잡히지 않음.

## 9. 법적·윤리적 고려사항

- **투자 자문이 아니다.** 모든 페이지에 다음 취지의 고지문을 표시한다.
  > 본 서비스는 금융감독원 전자공시(DART) 자료 등을 가공한 정보 제공 목적의 서비스이며, 투자 권유나 자문이 아닙니다. AI가 작성한 분석 글은 오류가 있을 수 있으며, 투자 판단과 그 결과의 책임은 이용자 본인에게 있습니다.
- **비상업 서비스**임을 모든 페이지 하단과 로그인 화면에 다음 취지로 안내한다 (F-Z6).
  > 본 서비스는 바이브코딩 수업을 위해 만든 비상업 프로젝트로, 수익을 목적으로 하지 않으며 광고·유료 기능이 없습니다. 주가 정보는 공공데이터포털 「금융위원회_주식시세정보」(출처: 한국거래소)를 이용 조건(출처표시·상업적 이용금지·변경금지)에 따라 비상업적으로 사용합니다. 뉴스 정보는 Google 뉴스 RSS로 찾은 기사 목록이며, 기사의 저작권은 각 언론사에 있습니다.
- AI 분석 글에 "매수", "매도", "추천", "목표주가" 같은 권유 표현을 쓰지 않는다.
- 분석 글의 **투자 포인트는 공시 숫자와 뉴스에 대한 해석**이며 투자 권유가 아니다. 매수·매도·보유 의견, 목표주가, 주가·수익률 예상은 쓰지 않고, 추정이 들어간 문장은 추정임을 드러낸다 (F-V12, F-V13).
- 서비스 목적과 무관한 질문·투자 권유 요청은 **정해진 문구로 공손하게 거절**한다 (§6.3.1). 거절 문구는 AI가 만들지 않는다.
- 뉴스 기사는 **제목·언론사·날짜·링크와 우리가 작성한 짧은 요지만** 표시하고, 본문을 옮겨 싣지 않는다.
- OpenDART·공공데이터포털 이용 조건(출처 표시 등)과 Google 뉴스 RSS 이용 조건(비상업 용도)을 준수한다.
- 개인정보 보호법에 따라 개인정보 처리방침을 공개하고 동의를 받는다.

| R9 | **외부 텍스트를 통한 AI 조작(프롬프트 주입)** | 공시 원문·기사 본문은 데이터로만 취급, AI는 도구 목록 밖 행동 불가, 회귀 테스트로 검증 |
| R10 | 질문 해석 오류 (엉뚱한 기업·지표) | 분석 기준 바에 해석 결과 표시, 후보가 여럿이면 되묻기 |
| R11 | **AI 오남용** (서비스를 범용 AI 챗봇처럼 사용, 권유·조작 유도) | 범위 판정 후 거절, 거절 문구는 서버의 고정 문구, 거절도 질문 수 차감, 회귀 테스트로 검증 (§6.3.1) |
| R12 | 범위 안 질문을 잘못 거절 | 기업·지표가 확인되면 범위 안으로 판정, 애매하면 거절 대신 되묻기 (F-U7), 오거절 회귀 테스트 |
