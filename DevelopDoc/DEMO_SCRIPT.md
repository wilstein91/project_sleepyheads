## 3. 시연 순서 · 말할 내용 · 기대 화면

### 0) 시작 — 비로그인 첫 화면 (30초)
- **말할 내용**: "상장사 재무 숫자를 질문 하나로 보여 주는 서비스입니다. 숫자는 전자공시 원문으로 계산하고, AI는 질문을 해석하고 설명만 씁니다. 로그인 전에도 예시 하나를 볼 수 있습니다."
- **기대 화면**: 첫 화면 아래 SK하이닉스 예시 결과(차트 + 분석 글)
- [로그인] → 구글 로그인 → (처음이면) 약관 동의 → 첫 화면

> **투자 리포트 (2026-10-01 추가)**: Q1~Q5 결과 위에 **"SK하이닉스 투자 리포트"** 핵심 지표(현재가·시가총액·PER·PBR·ROE·배당수익률·1년 수익률·52주 범위·최대주주), 차트 아래에 **기본 정보 → 주가·거래 → 재무·실적 → 밸류에이션 → 최근 12개월 중요 공시** 칸이 붙는다. 분석 글 투자 포인트는 **성장성·수익성·재무 안정성·밸류에이션·주가 흐름·이슈** 관점으로 묶여 나온다.
> - **말할 내용**: "질문에만 답하지 않고, 그 기업을 판단하는 데 필요한 숫자를 함께 계산합니다. 1년 주가 흐름, 5년 실적·현금흐름, 과거 평균·경쟁사와 견준 PER·PBR까지 — 숫자는 모두 공시와 주가 원문으로 계산하고, AI는 그 숫자들을 엮어 해석만 합니다."
> - Q1에서 리포트를 한 번 훑고(1분 더), Q2~Q5는 리포트가 같으니 질문에 대한 답과 분석 글만 본다.
> - 컨센서스·목표주가·외국인 수급은 "무료 공공 데이터에 없고, 투자 권유를 하지 않는 원칙이라 제공하지 않는다"고 화면에도 적혀 있다.
> - `warm-demo`가 리포트 캐시(1년 시세·사업보고서 5개·최대주주·배당·사업연도 말 주가)까지 미리 채운다.

### Q1) 단순 질문 — `SK하이닉스 최근 실적 어때?` (1분)
- **기대 화면**: 대기 화면(진행 표시) → 결과. 왼쪽 차트 매출·영업이익·순이익 **2025Q3~2026Q2**, 오른쪽 분석 글(결론 + 투자 포인트 2~4개), 아래 "사용된 데이터"(접수번호)
- **말할 내용**: "분석 글의 숫자는 모두 왼쪽 차트에 있는 숫자입니다. AI가 숫자를 지어내면 그 문장은 버립니다. 매수·매도 의견은 쓰지 않습니다."
- 2026Q2 **순이익(93.9조)이 매출(79.3조)보다 크게** 보이면: "반기보고서 원본 값 그대로입니다 — 계산 오류가 아닙니다" (HANDOFF §0.4)
- **막히면**: §4-A

### Q2) 추이 — `SK하이닉스 최근 8분기 영업이익 추이 보여줘` (1분)
- **기대 화면**: 영업이익 선/막대 **2024Q3~2026Q2** 8개 점, 전년 동기·직전 분기 증감률
- **보여 줄 것**: 차트의 **"표로 보기"**(Tab으로도 열림), 용어(영업이익 등)에 마우스를 올리면 한 줄 설명
- **막히면**: §4-A

### Q3) 복합 질문 + 보드 — `SK하이닉스 직전 분기 대비 영업이익 변화와 감소한 경쟁사 비교해줘` (4분)
1. **계획 카드**가 뜬다 — 기간 **2026Q2 ~ 2026Q2**, 단계(SK하이닉스 재무 수집 → 경쟁사 고르기 → 경쟁사 재무 → 결과·분석 글)
   - **말할 내용**: "여러 단계가 필요한 질문은 바로 실행하지 않고 계획을 먼저 보여 줍니다. 승인하기 전에는 질문 수도, AI 비용도 쓰지 않습니다."
2. [분석 시작] → 진행 표시 "n/4단계" → 결과. **실행 기록**을 펼쳐 `get_peers` "시가총액 순 (9월 30일 종가)" 줄을 보여 준다
3. **보드 필터** (같은 결과 화면):
   - 기간 프리셋을 바꾼다 → 모든 차트·표 제목의 기간이 같이 바뀜, **남은 질문 수 그대로**
   - 비교 기업 칩에 자동으로 고른 경쟁사가 그대로 있다(Phase 4 통합 수정) → 하나 빼기 → 비교 차트에서 빠짐 → 다시 넣기
   - 새로 고침 → 필터 유지
   - 분석 글 위 "원래 조건 기준 설명입니다" → [설명 다시 쓰기] → 질문 1회 차감, 새 조건 기준 글
   - 화면 위 버전 줄이 **"보드 데이터 버전"**과 원래 분석 버전을 구분해 보여 준다(Phase 5 화면 마감)
4. **말할 내용**: "필터를 바꾸는 것은 이미 받은 데이터로 DB 안에서 다시 계산하기 때문에 질문 수를 쓰지 않습니다. 설명을 다시 쓸 때만 AI를 부릅니다."
5. (시간 남으면) [같은 조건으로 재실행] → 같은 숫자
- **막히면**:
  - 계획 카드가 안 뜨고 바로 결과 → 그대로 진행(보드 필터만 보여 준다)
  - 자동 선택 경쟁사 칩이 비어 있다 → §4-B 대체 질문
  - 90초 상한으로 분석 글 앞에서 멈춤 → "차트·표는 이미 나왔고, 글은 [다시 시도]로 이어서 씁니다"라고 말하고 [다시 시도], 안 되면 §4-A

### Q4) PER·PBR — `SK하이닉스 PER 알려줘` (1분)
- **기대 화면**: 지표 카드 **시가총액·PER·PBR**, PER 약 **8.01배**, 카드 아래 **"기준일 9월 30일 종가"**, 지표 옆 **ⓘ** 누르면 계산식(PER = 시가총액 ÷ TTM 지배주주 순이익 — TTM은 최근 4개 분기 합)
- **말할 내용**: "주가는 금융위원회 주식시세 API에서 하루 한 번 받습니다. 재무와 주가를 합칠 때 같은 날짜가 두 번 나오면 결합을 멈추고 경고를 띄웁니다."
- **막히면**: 카드가 "계산 불가"면 그날 주가를 아직 못 받은 것 → §4-A(리허설 결과)

### Q5) 뉴스 단서 — `SK하이닉스 2026년 2분기 영업이익이 왜 늘었어?` (1분 30초)
- **기대 화면**: (계획 카드가 뜨면 [분석 시작]) → 분석 글 투자 포인트에 **[뉴스 1]** 같은 표시, 아래 "뉴스 단서" 카드(제목·언론사·날짜, Google 뉴스 링크)
- **말할 내용**: "원인은 숫자만으로 단정하지 않습니다. 뉴스 제목을 단서로만 붙이고, 기사 속 명령문은 데이터로만 다룹니다."
- **막히면**: 뉴스 단서가 0건 → "뉴스를 찾지 못하면 원인을 단정하지 않고 '확인할 점'으로만 씁니다"라고 말하고 넘어간다 (2026-10-01 `pnpm check:keys`에서 Google 뉴스 RSS가 HTTP 404 — 리허설 때 반드시 확인, §5)

### Q6) 정중한 거절 — `SK하이닉스 지금 사도 돼?` (30초)
- **기대 화면**: 투자 권유 거절 안내 + 대신 할 수 있는 질문 추천, "질문 1회가 사용되었습니다" 안내(판정에 AI 비용이 들어 거절도 차감 — PRD F-U8)
- **말할 내용**: "매수·매도 판단은 하지 않습니다. 서비스 범위 밖 질문과 지시를 바꾸려는 질문도 같은 방식으로 거절합니다." (회귀 세트: 실제 AI 거절 14/14, 오거절 0/11)

### 끝) 마무리 (30초)
- `/me` 내 분석 목록 — 오늘 질문이 모두 저장되어 있다
- "숫자는 원문, AI는 해석과 설명만, 투자 권유 없음" 한 문장으로 정리

## 5. 리허설 1회 (운영, AI 토큰 사용)

- **한 번만** 한다(시연용 토큰). 병합 배포 뒤, 시연 전날.
- §3 순서대로 Q1~Q6 + 설명 다시 쓰기 1회. 이 결과들이 §4-A 대안이 된다.
- 리허설에서 함께 확인해 [STEP5_PASS_TEST](./STEP5_PASS_TEST.md)에 적을 것: PER 카드·ⓘ, 자동 선택 경쟁사 칩 유지, `VersionBar` 보드 버전 표시, 뉴스 단서(RSS 404 여부), 거절, 걸린 시간
- 끝나면 `api_usage_daily`(읽기만)로 오늘 AI 비용을 적는다
