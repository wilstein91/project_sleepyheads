# 투자 리포트 개편 — 예림 (`feat/P5-report`)

2026-10-01, Phase 5 병합 뒤. 결정: "질문에 숫자 두 개로만 답하는 것은 분석이 아니다" → **기업 질문마다 투자 리포트**, 서버·화면·분석 글 모두 예림이 한 PR로, **시연 전에** 넣는다 (예림, 2026-10-01).

## 무엇이 바뀌나 (사용자 화면)
- 기업 하나가 대상인 모든 질문의 결과 위에 **"○○ 투자 리포트"** 핵심 지표: 현재가(등락률)·시가총액·PER·PBR·ROE·배당수익률·1년 수익률·52주 범위·최대주주(지분율).
- 질문 차트 아래에 리포트 칸 5개 (TECH §12.6):
  1. **기본 정보** — 종목·시장·업종(근거)·결산월·시가총액·상장주식수·최대주주·특수관계인 포함 지분율·주당 배당금
  2. **주가·거래** — 현재가·등락률·시가/고가/저가·거래량·거래대금·52주 최고/최저·52주 범위 위치·연율 변동성·20일 거래량 배수 / 1년 주간 종가·기간 수익률(1·3·6개월·1년·연초 대비)·주간 거래량 차트
  3. **재무·실적** — 최근 분기 실적과 YoY·QoQ·영업이익률·ROE·부채비율, EPS·ROA·유동비율·매출 연평균 성장률 / 8분기 실적·분기 영업이익률·5개 사업연도 실적·수익성·현금흐름(영업현금흐름·설비투자·잉여현금흐름)·재무 안정성 차트
  4. **밸류에이션** — PER·PBR·PSR·PCR·배당수익률·배당성향, **과거 평균 PER·PBR 대비 현재**, 경쟁사 PER·PBR 중앙값 / 사업연도 말 PER·PBR 추이, 경쟁사 비교 표
  5. **최근 12개월 중요 공시**
- **분석 글**: 결론 2~5문장(필요할 때만 늘림 — 질문의 답 → 기업 전체 상태 → 주의할 점), 투자 포인트 최대 8개를 **성장성·수익성·재무 안정성·밸류에이션·주가 흐름·이슈** 관점으로 묶는다. 숫자 두 개 이상을 엮어 해석하도록 지시문을 바꿨다. 자리표시자 뒤 조사(이/가·은/는·으로/로…)는 서버가 값에 맞춘다("89조 원**이**", "8.01배**는**").
- **제공하지 않는 것** (화면에 밝힘): 외국인·기관 순매수·공매도, 사업부문별 매출 비중, EV/EBITDA, 컨센서스·목표주가·투자의견(데이터 없음 + 투자 권유 금지). 매수·매도·저평가 판정 금지는 그대로.

## 실제 데이터로 확인 (2026-10-01, 팀 DB 안 씀 — 메모리 DB + 실제 전자공시·주가 API)
- SK하이닉스 리포트 1.6초(캐시 없이 외부 호출 30~43건), 숫자 약 250개 — PER 8.01배·PBR 4.94배(회귀 정답과 같음), 과거 평균 PER 12.97배(4개 흑자 사업연도)·PBR 1.99배, 2023 적자 연도는 PER 빈칸, 최대주주 SK스퀘어 20.50%, 경쟁사 삼성전자·한미반도체.
- 실제 AI로 분석 글 1회(gpt-6-sol, $0.024, 13.7초): 이익이 매출보다 빨리 늘었다·영업현금흐름이 설비투자를 웃돈다·PER은 과거 평균보다 낮지만 PBR은 높아 배수별 평가가 엇갈린다·최근 3개월 수익률이 1년 수익률과 방향이 다르고 변동성이 크다 — 관점 6개. 이때 찾은 조사 문제("원가", "배은")를 고쳤다.

## 구조
- `src/lib/report/` — `price-history.ts`(1년 일별 시세, 종목당 하루 1회 · 통계는 순수 함수), `annual.ts`(사업보고서 5개 + 최근 정기보고서의 리포트용 계정), `facts.ts`(최대주주·배당), `build.ts`(조립), `carry.ts`·`ids.ts`.
- 만드는 곳: **`build_result` 단계 안** (단계를 늘리지 않음 — 시간·비용 상한에 안 걸리고, 실패해도 질문의 답은 그대로). 실행 기록 `build_result` 요약에 `투자 리포트: 주가 252거래일 · 사업보고서 5개 · … · 외부 호출 n건`.
- 숫자 ID **f100001~**, 차트 ID **r1~** (질문 결과와 겹치지 않음). 같은 조건 재실행·보드 다시 계산은 원래 리포트를 그대로 붙인다.
- 분석 글 AI에는 리포트 요약 + 핵심 숫자(`keyFigureIds`)만 — 주간 차트 점 100여 개는 뺀다.
- **분석 글 재사용**: 리포트가 있으면 **같은 주가 기준일 리포트로 쓴 글(관점 있음)만** 재사용 — 리포트 전 글이나 다른 날 주가로 쓴 글을 다시 보여 주지 않는다.
- `warm-demo`가 리포트 캐시도 채운다 (표에 "리포트 호출").

## 비용·시간
- 분석 글 AI 비용이 한 번에 약 $0.02~0.03 (입력이 커짐). 질문당 AI 상한은 **$0.03 → $0.05**(마이그레이션 `20261001220000`, 데이터만). 상한은 단계 **시작 전**에만 보므로 분석 글은 끊기지 않는다. 하루 분석 글 예산 `OPENAI_EXPLAIN_DAILY_BUDGET_USD`($1)를 넘으면 그날은 저가 모델 — 시연일에 많이 묻는다면 Vercel 값을 올리는 것을 검토.
- 리포트 첫 조회: 외부 호출 약 30~45건(사업보고서·분기 보고서 연결/별도, 1년 시세 1, 사업연도 말 주가 5, 최대주주·배당 2, 경쟁사). 두 번째부터는 주가 1년 시세(하루 1회)만.
